# Blank Streamlit App

A minimal Streamlit starter repository for quickly testing app ideas, deployment wiring, and small interactive prototypes.

[![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://blank-app-template.streamlit.app/)

## What It Does

The app currently renders the default Streamlit starter screen from `streamlit_app.py`. It is intentionally small so it can be reused as a clean baseline.

## Local Setup

1. Install the requirements

   ```sh
   pip install -r requirements.txt
   ```

2. Run the app

   ```sh
   streamlit run streamlit_app.py
   ```

## Repository Status

This is a sandbox/template repository, not a production application.
